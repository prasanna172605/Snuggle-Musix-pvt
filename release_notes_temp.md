## Snuggle Musix v1.0.0 — Initial Release

Welcome to **Snuggle Musix**, a premium, privacy-first Android music player.

### What's New
- Ad-free YouTube Music streaming with automatic format resolution
- Word-by-word synchronized lyrics (LRCLib, MusixMatch, YouLyPlus)
- **Liquid Glass UI** — Apple-inspired translucent UI overlay with dark black theme
- Smart storage management — app data capped at ~150 MB, cache at 256 MB
- Smart local library integration
- Offline-first caching with intelligent cleanup

### Installation
1. Download **snuggle musix.apk** below
2. Enable "Install from unknown sources" in Android Settings
3. Install and enjoy

### Updating from v6.0.3
Direct install over the old version is supported — just install the APK and your library/playlists will be preserved.

### System Requirements
- Android 8.0+ (API 26+)
- ARM64 device (arm64-v8a)
- ~65 MB storage for installation
