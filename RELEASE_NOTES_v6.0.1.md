# Snuggle Musix v6.0.1

### 🚀 What's New & Improvements
- **⚡ Playback Stutter & Infinite Loading Fix**: Optimized YouTube InnerTube client fallback order (`IOS`, `IPADOS`, `MOBILE`, `WEB_REMIX`, `ANDROID_CREATOR`) to prevent bot mitigation and sign-in challenge loops.
- **🎵 Classic Mini Player**: Added a persistent toggle switch in *Settings > Appearance* to alternate between the classic docked mini player and the floating pill mini player.
- **🍎 Apple-Inspired UI**: Added an Apple-inspired music player layout option in Appearance Settings.
- **🎨 Redesigned Theme Screen**: Integrated ViVi Music-style theme cards (Appearance Mode, Pure Black AMOLED mode, Dynamic Material You Monet card, and Curated Color Palettes).
- **🧹 Clean Architecture**: Completely removed Snuggle Brain from databases, repositories, viewmodels, menus, and UI.
