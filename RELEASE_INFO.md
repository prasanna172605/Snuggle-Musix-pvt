# Snuggle Musix v6.0.2

### 🚀 What's New & Improvements
- **⚡ Fast Loading & Playback Stream Fix**: Prioritized `WEB_REMIX` as the main playback client to prevent bot challenges, sign-in lockout loops, and play stalling.
- **📝 Onboarding Name Prompt**: Added a text field directly on the initial Welcome screen so users can set their preferred username when first launching the app.
- **🧹 Cleaned Service Uptime**: Removed the offline Qobuz status check to keep service monitors clean.
- **⚙️ CI Automation Fixes**: Resolved Discord notification trigger issues on custom builds.
